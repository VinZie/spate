Spate browser integration

Send downloads, links and detected streams to the Spate download manager.

Download capture

Separate with spaces or commas. Wildcards work: r?? matches r00, r01…; part* matches part1, part2…

KB (0 = no minimum; only applied when the browser knows the size)

Excluded sites

One pattern per line. example.com also covers its subdomains, * and ? are wildcards, and a pattern with a path (example.com/downloads/) matches addresses starting with it.

Media detection

Detected media appear in the toolbar popup and in the page's context menu. DASH (.mpd) streams are listed but cannot be downloaded yet.

Connection

Not tested yet.

The extension talks to the native messaging host com.spate.host, which is installed by running spate-cli install-host. It registers this extension (ID ) as allowed to use it.
